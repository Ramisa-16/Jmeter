## 📋 Test Types

| Type | Description |
|---|---|
| Load Testing | Simulate expected user load |
| Stress Testing | Find breaking point |
| Spike Testing | Sudden traffic surge |
| Endurance Testing | Sustained load over time |

---

## 🚀 Getting Started

1. Install [Apache JMeter](https://jmeter.apache.org/download_jmeter.cgi)
2. Open JMeter → `File → Open → select .jmx`
3. Configure thread count and ramp-up
4. Run test → View Results Tree / Summary Report
